# Seed My Wallet

Free Solana devnet test data.

Seed My Wallet fills a Solana devnet wallet with test data: SPL and Token-2022 tokens, NFTs, compressed NFTs, ZK-compressed tokens and empty token accounts, delivered one by one and tracked live, so developers and their agents can test wallets and dApps on devnet instead of mainnet.

It's devnet only, free and anonymous. It needs your wallet's address and nothing else. It never asks for a private key or a seed phrase.

Ordering opens soon at seedmywallet.com, through a web page, a public `/v1` API and an MCP server for agents.
