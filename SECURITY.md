# Security policy

This policy covers every public Seed My Wallet repository that doesn't have its own.

## Reporting a vulnerability

Please don't open a public issue, discussion or pull request for a security problem.

Report it privately through GitHub: open the affected repository's **Security** tab and choose **Report a vulnerability**. For a problem with Seed My Wallet itself, its site or its API, use [this private form](https://github.com/seedmywallet/.github/security/advisories/new).

Include what is affected (a repository, a package and its version, or a URL), the steps to reproduce it, and what an attacker could do with it.

## What happens next

We reply to every report and keep you updated until it's resolved. Please give us a reasonable time to fix the problem before you share details publicly. Once it's fixed, we credit you if you'd like that.

## Supported versions

Security fixes go into the latest version of each repository and package. Older versions don't get patches.
